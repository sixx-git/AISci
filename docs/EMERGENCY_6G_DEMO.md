# 溯源智研 · 6G 专业应用

通用科研和联邦学习资源包仍然可以从「创建新项目」进入。6G 是第三条入口，不替换前两者。

## 启动

```bat
scripts\run_dev.bat
```

前端 http://localhost:5173 ，后端 http://localhost:8000 。

## 专题

| 专题 | 快速预检 | 完整科研分析 |
|---|---|---|
| 空天地融合应急通信 | 已有的容量、续航、设备数量和参数检查 | 同一项目进入「智能体工作流」，跑原有七阶段 |
| 边缘智能与算网协同 | 显示待专业验证，不生成仿真数字 | 用专题模板中的研究问题进入七阶段 |
| 通感一体化研究 | 显示待专业验证 | 同上 |
| 用户自定义6G任务 | Qwen 解析领域、目标和参数；数字需人工核对，且标记为非实测 | 核对后进入七阶段 |

大家长只把预检反馈和版本记入项目。它不判定方案能否部署。

检查数字由 `deterministic_rules_v1` 计算，保存在 `project.config.emergency_comm`。Qwen 只用于自定义任务解析，不用于判定预检是否通过，也不改写应急方案。

## 应急通信演示

1. 创建项目，选择「6G专业应用」→「空天地融合应急通信」。
2. 打开「6G专题」。版本 1 应算出 30 Mbps 超过 20 Mbps，且 90 分钟超过 60 分钟续航。
3. 确认「改为优先保障救援终端」。版本 2 容量通过、续航不通过，状态为部分解决。
4. 点击「将当前记录写入报告」。报告中的 30、20、失败项来自这次预检记录。
5. 需要文献、假设和正式研究报告时，点击「进入完整科研分析」。报告生成后会附上同一份预检记录。

边缘智能和通感专题不要期望出现时延、能耗或检测概率的通过结论。页面应保持「待专业验证」。
