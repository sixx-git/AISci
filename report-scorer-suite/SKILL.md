# 报告评分套件（report-scorer-suite）

一个文件夹内含两套互补的评分方法，共享脚本与输出格式。

- **方法 A · 客观加权评分**（`scripts/score.py`）：从报告里写明的信号机械算分 → 公平、可复现、无偏好。
- **方法 B · 科学家评分**（`scripts/extract_text.py` + 大模型逐篇精读 + `scripts/calibrate.py`）：大模型以人类科学家(PI)人格带偏好打分 → 专家主观印象。

两者都支持把均值校准到目标值（默认 85），放在同一量尺上直接对比；**分歧最大的篇目**最值得重点研读。

## 方法 A · 客观加权评分（根据报告自身信号）

### 七层加权模型（合计100%；科研四层 L2-L5 合计85%）
| 层 | 维度 | 权重 |
|---|---|---|
| L0 | 类型识别 | 5%（降权） |
| L1 | 形式合规 | 5%（降权） |
| L2 | 选题与问题 | 20% |
| L3 | 方法学 | 25% |
| L4 | 证据强度（样本量+结论自我限定；已删轮次/效应量/外推） | 25% |
| L5 | 诚实度 | 15% |
| L6 | 可用性 | 5%（降权） |

### 各层子指标与 0–100 口径
- **L0**：是否透明自标 AI/smoke/代理 → 100，否则 50。
- **L1**：摘要/方法/结果/讨论/参考文献 各12分(共60)；有结论段+20；有"待研究问题/引言/背景"+20。
- **L2**：问题真实性(50%)＝"研究缺口/缺乏/尚未"且文献≥4→100，否则60；跨学科牵强(50%)＝标题学科桶≤1→100，=2→60，≥3→30。（*启发式，需领域专家终审*）
- **L3**：可检验性(25%)；泄漏/平凡解(25%，自报越多越扣)；显著性检验(25%)；代理-命题匹配(25%，宏大命题+通用表格ML→低)。
- **L4**：样本量(50%)；结论自我限定(50%)。
- **L5**：局限声明(40)、负向/失败保留(35)、不确定性量化(25)。
- **L6**：有真实数据集+40；文献≥5→+30；有具体指标→+30。

### 运行
```
<venv>/Scripts/python.exe scripts/score.py --dir <PDF文件夹> [--target-mean 85] [--out <输出>]
```
输出 `weighted_scores.csv`（含 composite 校准分、composite_raw 未校准分、L0-L6、原始信号）与 `评分卡.md`。

### 公正性红线
1. 自动评分=初筛非终审：L2跨学科牵强、L3命题匹配度须领域专家复核。
2. 信号可回溯：CSV 保留原始信号列。
3. 不双重惩罚：如实披露泄漏拉低L3但抬高L5。
4. 基准统一：同基准、同权重、同口径。

## 方法 B · 科学家评分（大模型扮演人类科学家带偏好）

### 人格与偏好（评分前注入系统设定）
> 你是一位严谨但**建设性、鼓励型**的[领域]人类科学家（正教授/PI）。把这些报告视为**探索性前期草案**（自动化生成的 smoke 草稿），按"建设性前期评审"给分：**基础分约 70**，扎实处加分、薄弱处扣分，但**不按已发表顶刊标准苛责**。偏好：
> 1. 重单一清晰贡献，对泛泛而谈适度扣分（不归零）。
> 2. 理解代理/smoke 是可行性探测阶段，给"探索分"而非 0 分。
> 3. 对宏大命题审慎但肯定探索价值，不因题目大直接低分。
> 4. 欣赏真实数据+恰当方法+显著性检验，明确加分。
> 5. 看重领域深度，对跨学科拼贴温和扣分。
> 6. 对诚实局限声明明确加分，并作为整体温和正面项。
> 7. 对 AI 生成八股温和看待。
> 8. 偏好可复现（有代码/数据/协议加分）。
> （整体落 70–92 区间。）

### 五维评分（权重）
选题价值 20 / 方法恰当性 25 / **证据强度 30** / 贡献清晰度 15 / 表达与诚实度 10。

### 运行
1. 抽文本：`<venv>/Scripts/python.exe scripts/extract_text.py --dir <PDF文件夹> --out <PDF文件夹>/_texts`
2. 大模型逐篇（或每批 3–5 篇）读 .txt，按上面人格与格式打分，填表：`file, 选题, 方法, 证据, 贡献, 表达诚实, 总分, 评语, 主要扣分点`。
3. （可选）校准：`python scripts/calibrate.py --csv scientist_scores.csv --target-mean 85` → 生成 `scientist_scores_calibrated.csv`（新增 `总分_cal`）。

### 透明声明
- 本分数来自大模型**以科学家人格的判断**，仍属模型输出；偏好由人格设定决定，换设定即变。
- 与客观版互补：客观保公平可复现，本版供专家印象；二者并列时分歧点最有信息量。

## 两法对照（建议做法）
- 同一目录各跑一次 A 与 B。
- 对比排名，**分歧大**的篇目通常：客观信号还行但科学家嫌"proxy/标题唬人/贡献不清"→科学家分更低；或反之。
- 这些正是最该重点研读/人工复核的报告。

## 脚本清单（scripts/）
- `score.py`：方法 A 客观加权评分器（--dir/--target-mean/--out）。
- `extract_text.py`：方法 B 文本抽取（PDF→txt）。
- `calibrate.py`：方法 B 科学家分校准到目标均值（默认85）。
