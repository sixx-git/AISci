# 业务理解

- 软件名称：联邦智研AI科研自动化系统
- 产品定位：联邦智研AI科研自动化系统（项目代号 AISci）是一套以国产大模型 Qwen（千问）为底座构建的多智能体科研自动化软件。系统把科研活动中“提出问题—检索证据—生成假设—验证假设—形成报告”的科学逻辑链，封装为一条可复现、可审计、支持人在回路（HITL）的七阶段标准 Pipeline，供科研人员在浏览器中完成从研究问题到带完整证据链的研究报告的全程自动化操作。
- 面向领域 / 行业：科研信息化 / 人工智能科研辅助软件
- 核心价值：用事实白名单约束引用、用判定式门禁拦截不可行方案、用“大家长”Agent 统筹全局质量，让大模型参与的科研过程做到证据可溯源、质量可判定、风险可前置，把原本依赖个人经验的科研流程组织为分钟级、可追溯的工作流。
- 证据文件：`业务理解证据.md`

## 目标用户

- 高校与科研院所的科研团队（导师与学生）
- 攻读学位、需要撰写开题报告与科研报告的研究生
- 参加大创、挑战杯、揭榜挂帅等科研类赛事的学生团队
- 需要快速完成文献调研、假设构建与报告撰写的个人研究者

## 主要业务功能

- 七阶段科研自动化 Pipeline
- 多智能体协作
- 事实白名单证据链迭代
- 知识库对齐与小样本预检双重过滤
- 大家长 Agent 全程质检与自动修复
- 人在回路审核 Gate
- 综合质量分与审计链导出
- 科学影响力预测
- 联邦学习 Starter Pack

## 功能说明

- 七阶段科研自动化 Pipeline：系统按固定顺序执行七个阶段：问题理解解析研究目标与边界；文献挖掘从 arXiv 与私有文献库提取结构化事实；知识缺口识别尚未解决的新挑战与矛盾；假设生成基于事实白名单产出可检验假设；假设评审做五维评分与红蓝对抗；迭代实验在沙箱中按反馈多轮执行并自检；报告生成输出带参考文献与图表的科研报告。阶段间由 CoordinatorAgent 衔接。
- 多智能体协作：每个阶段由一个专用智能体负责（ProblemUnderstandingAgent、LiteratureMiningAgent、KnowledgeGapAgent、HypothesisGenerationAgent、HypothesisReviewAgent、报告生成 Agent 等），CoordinatorAgent 负责 Agent 间记忆管理、全局跟踪与阶段切换。
- 事实白名单证据链迭代：文献挖掘阶段从论文中提取结构化知识，每条 Fact 绑定唯一 fact_id 与 source_chunk_id，形成事实白名单。后续假设生成、评审与报告撰写只能引用白名单中真实存在的 fact_id，证据不足时系统可自动触发补搜或沙箱验证，并支持证据链多轮迭代。
- 知识库对齐与小样本预检双重过滤：系统用一组判定式 Gate（如事实对齐、方案可执行性、数据充分性）在假设与实验设计阶段做双重把关：没有事实依据的假设不通过，理论上不成立或实际跑不通的方案被提前拦截，从源头规避无效算力与伪成功报告。
- 大家长 Agent 全程质检与自动修复：CoordinatorAgent 贯穿全流程，基于预设常见问题规则库主动拦截低质量输出，并在报告生成后自动修复内容“机器味儿”问题（如重复标点、结构错位），把每一阶段的质量结果与人工意见带回后续环节。
- 人在回路审核 Gate：在假设评审、报告发布等关键节点设置人工审核 Gate，专家可查看系统提示与证据级别，选择“通过”或“退回修改”，使自动化流程在失控前得到人工纠偏。
- 综合质量分与审计链导出：系统对每阶段产出计算综合质量分（CQS），并在 Pipeline 运行目录记录审计链（events/decisions/quality trend），用户可在报告中心导出 JSONL 审计链与证据链，逐条回放决策依据。
- 科学影响力预测：延伸的评分表系统整合 OpenAlex 引用数据、论文文本特征与生命周期模型，对生成报告做四维评估（文本质量/声誉网络/未来影响/偏差公平）并量化不确定性，明确区分文本质量贡献与已有声誉影响，抑制光环效应。
- 联邦学习 Starter Pack：以内容注入方式提供联邦学习文献种子、数据集元数据与本地可跑脚本，作为通用科研能力的扩展演示；创建联邦学习模式项目时可在 UI 选择 FL 档位与仿真后端，通用模式不挂载相关面板。

## 典型操作流程

1. 在首页或“新建项目”页创建科研项目，填写研究问题、研究领域、目标与约束，选择通用或联邦学习模式。
2. 进入项目工作台，系统在“研究问题”Tab 调用问题理解智能体解析目标与边界。
3. 在“文献库”Tab 上传 PDF/导入 arXiv 文献，文献挖掘智能体提取事实白名单（fact_id 与来源）。
4. 知识缺口智能体识别尚未解决的新挑战，假设生成智能体基于事实白名单产出 3–5 条可检验假设。
5. 在“候选假设”Tab 查看五维评分与证据级别；遇到人工审核 Gate 时，专家通过或退回修改。
6. 在“迭代实验”Tab 绑定数据、设计分析脚本，系统先小样本预检再执行多轮迭代，失败可触发证据链迭代。
7. 报告生成阶段产出带参考文献与图表的研究报告，用户可查看 CQS 与修复状态。
8. 在“研究报告”或报告中心导出 Markdown/PDF 与审计链 JSONL，用于复盘、提交或参赛材料。

## 操作手册页面/流程模块

1. 首页与项目列表：浏览器访问 http://localhost:5173 后默认进入首页（路由 /）。
   - 使用场景：科研人员每天打开系统第一眼看到的就是首页：这里列出自己参与的全部项目，可按名称或状态筛选，也能从首页直接进入某个项目的工作台或发起新项目。
   - 操作要点：在搜索框输入项目关键字，或点击状态标签筛选列表。；点击某张项目卡片，进入该项目的多 Tab 工作台。；点击右上角“创建项目”按钮，跳转到新建项目页。
2. 新建科研项目：首页点击“创建项目”，或访问 /projects/new。
   - 使用场景：当用户有一个新的研究想法（例如“部分类不相交数据下的联邦学习鲁棒性”）要系统化推进时，在此页填写研究问题、目标与约束，建立项目骨架。
   - 操作要点：填写项目名称与研究问题（必填）。；选择项目模式；若选联邦学习，继续选择 FL 档位与领域标签。；填写研究目标、背景、约束与期望输出等可选项。；点击“创建”，系统生成项目并返回工作台。
3. 项目工作台与多 Tab 导航：首页点击项目卡片，或访问 /projects/:id。
   - 使用场景：用户进入具体项目后，日常所有操作都在工作台进行：切到不同 Tab 分别处理问题、文献、假设、实验与报告，无需在多个系统间跳转。
   - 操作要点：在 Tab 栏点击目标阶段对应的标签。；在当前 Tab 内完成该阶段操作（如研究问题 Tab 查看/编辑问题陈述）。；需要深入配置时，通过高级深链进入 Prompt 管理或运行日志 Tab。
4. 智能体工作流运行（七阶段 Pipeline）：项目工作台 → “智能体工作流”Tab（WorkflowPage）。
   - 使用场景：用户在工作流 Tab 启动一次完整科研运行，实时观察问题理解→文献挖掘→知识缺口→假设生成→假设评审→迭代实验→报告生成的推进，并在人为审核节点介入。
   - 操作要点：点击“启动 Pipeline”，系统按七阶段顺序执行。；观察进度条与每个阶段产出；遇到人工审核 Gate 时，在弹窗中查看证据并选择通过或退回。；某阶段完成后可点击查看详细输出；运行结束在运行过程时间线查看质量趋势。；点击“导出审计链”下载本次运行的 JSONL 决策记录。
5. 文献库与事实白名单（证据链抽屉）：项目工作台 → “文献库”Tab（LiteratureLibrary）；证据链抽屉由假设或事实链接打开。
   - 使用场景：用户在文献库 Tab 上传论文或导入检索结果后，想确认系统到底依据哪些文献事实生成了假设，可打开证据链抽屉查看每条 fact 的来源与证据级别。
   - 操作要点：点击“上传”选择本地 PDF/DOCX，或点击“导入”检索并添加 arXiv 文献。；等待文献挖掘完成，列表中显示已提取的事实数量。；点击某条事实或假设中的 fact 引用，打开证据链抽屉查看来源原文与来源块标识。；根据证据级别（high/medium/low）判断该事实的可信度。
6. 候选假设与评审（人在回路 Gate）：项目工作台 → “候选假设”Tab（HypothesesPage）；HITL 弹窗在评审 Gate 触发时自动出现。
   - 使用场景：用户在假设评审阶段后，于候选假设 Tab 查看系统产出的多条假设及其评分，对关键假设做人工通过/退回，控制自动化流程的走向。
   - 操作要点：浏览假设卡片，查看五维评分与证据级别徽标。；点击某条假设展开其 fact 引用与评审摘要。；出现审核 Gate 时，在弹窗中阅读系统提示，选择“通过”或“退回修改”。；退回的假设会回到生成/修订环节，通过后进入迭代实验。
7. 迭代实验与运行决策：项目工作台 → “迭代实验”Tab。
   - 使用场景：用户在假设评审通过后，于迭代实验 Tab 选择数据、配置实验循环、查看反事实预演（失败模式预警），并基于每轮结果决定是否继续或转向。
   - 操作要点：在循环配置面板选择数据集并设定实验参数。；查看反事实预演给出的失败风险与最小成本验证建议。；点击“运行”，系统先小样本预检再执行 full 迭代。；逐轮查看指标；证据不足时点击“触发证据链迭代”回到文献补搜。
8. 研究报告生成与导出：项目工作台 → “研究报告”Tab，或顶栏“报告中心” /reports。
   - 使用场景：用户在七阶段运行完成后，于报告中心浏览生成的科研报告，检查参考文献与图表，并导出 PDF/Markdown 与审计链 JSONL 作为交付物。
   - 操作要点：在报告列表点击某份报告进入预览。；通读章节、参考文献与图表，确认证据链完整。；点击“导出 PDF”或“导出 Markdown”下载报告。；点击“导出审计链”下载 JSONL，逐条回放决策依据。
9. 文献中心（上传与检索）：顶栏“文献” /documents。
   - 使用场景：用户希望把一批论文集中管理、并在不同项目间复用检索结果时，在文献中心统一上传与检索，再在各项目文献库按需引用。
   - 操作要点：选择当前查看范围（某项目或跨项目汇总）。；点击上传添加本地文献，或在检索框输入关键词检索 arXiv。；从检索结果中勾选论文并“导入”到项目。；在列表中查看已入库文献与处理状态。
10. 科学影响力预测：顶栏“预测” /predict（需评分表服务运行）。
   - 使用场景：用户在报告完成后，想快速判断其潜在学术影响力与被高估风险时，在预测页提交报告，查看文本质量、声誉网络、未来影响与偏差公平四维结果。
   - 操作要点：在预测页选择或上传待评估的报告/论文。；点击“运行预测”，等待评分表服务返回。；查看四维分项、校准总分与偏差提示。；根据不确定性量化判断结果可信度。
11. 系统设置（LLM 配置）：顶栏“设置” /settings。
   - 使用场景：用户在首次部署后进入设置页，确认或填写 Qwen API Key，或在无 Key 时开启模拟模式，使后续 Pipeline 能正常调用模型。
   - 操作要点：在设置页选择 Qwen 作为基座模型。；填写 DashScope API Key（或在无 Key 时打开模拟模式开关）。；点击“保存”，前端提示配置已更新。；回到工作流启动 Pipeline 验证是否可调用。
12. Skills 管理与 Prompt 控制台：顶栏“Skills” /skills，或工作台高级深链“Prompt 管理”。
   - 使用场景：高级用户在想调整系统行为时，于 Skills 页查看可用技能（文献、证据推理、数据发现等）并启停，或在 Prompt 控制台为某项目覆盖特定阶段的提示词。
   - 操作要点：在 Skills 页浏览技能分类，打开或关闭所需技能。；进入 Prompt 控制台，选择目标阶段与预设范式。；编辑提示词或载入预设，点击“保存为项目覆盖”。；返回工作流，新运行将采用覆盖后的提示词。

- 开发目的：实现科研全流程自动化与证据可溯源管理
- 软件的主要功能：联邦智研AI科研自动化系统以国产大模型 Qwen 为底座，将科研全流程封装为可由科研人员在浏览器中操作的七阶段自动化 Pipeline。第一条主线是问题理解与文献挖掘：系统解析用户研究问题，从上传的 PDF 与 arXiv 文献中提取结构化知识，为每条事实分配 fact_id 与来源标识，形成事实白名单。第二条主线是知识缺口与假设：知识缺口智能体识别尚未解决的新挑战与文献矛盾，假设生成智能体基于白名单产出 3–5 条可检验假设，并强制要求每条假设引用真实 fact_id；假设评审智能体从科学价值、创新性、可检验性、数据可用性、成本风险五个维度评分，并引入红蓝对抗与证据级别标记。第三条主线是迭代实验与报告：系统在沙箱中按反馈多轮执行实验，先小样本预检拦截跑不通的方案，失败时可自动触发证据链迭代；报告生成阶段产出带参考文献与图表的研究报告，并基于预设规则自动修复内容质量。贯穿全程的 CoordinatorAgent（大家长 Agent）负责 Agent 间记忆、全局质量监控与自动修复，关键节点设置人在回路审核 Gate 供专家通过或退回。系统还计算综合质量分（CQS）、记录可回放的审计链，并提供科学影响力预测（评分表系统）对报告做早期可解释的影响力评估，以及联邦学习 Starter Pack 作为扩展演示。最终用户在报告中心导出报告与审计链，用于科研复盘、开题或赛事提交。
