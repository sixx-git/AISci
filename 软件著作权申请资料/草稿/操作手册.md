## 二、说明

联邦智研 AI 科研自动化系统 V1.0适用于科研信息化 / 人工智能科研辅助软件场景。用户进入系统后，可以围绕实际工作内容完成账号进入、业务创建、过程查看、结果确认和资料管理等操作。

日常使用时，高校与科研院所的科研团队（导师与学生）、攻读学位、需要撰写开题报告与科研报告的研究生、参加大创、挑战杯、揭榜挂帅等科研类赛事的学生团队、需要快速完成文献调研、假设构建与报告撰写的个人研究者可以按照页面提示从入口进入相应页面，查看当前业务状态，并根据页面中的按钮、输入框、列表或弹窗继续处理。用事实白名单约束引用、用判定式门禁拦截不可行方案、用“大家长”智能体 统筹全局质量，让大智能服务参与的科研过程做到证据可溯源、质量可判定、风险可前置，把原本依赖个人经验的科研流程组织为分钟级、可追溯的工作流。

联邦智研 AI 科研自动化系统（项目代号 AISci）是一套以国产大智能服务 Qwen（千问）为底座构建的多智能体科研自动化软件。系统把科研活动中“提出问题—检索证据—生成假设—验证假设—形成报告”的科学逻辑链，封装为一条可复现、可审计、支持人在回路（HITL）的七阶段标准 Pipeline，供科研人员在浏览器中完成从研究问题到带完整证据链的研究报告的全程自动化操作。

本操作手册与下列项目文档配套使用，读者可在软件安装目录或源码仓库中查阅：

联邦智研 AI 科研自动化系统是一套以国产大智能服务 Qwen 为底座的多智能体科研自动化软件，面向高校科研团队、研究生与科研类赛事团队，将“提出问题—检索证据—生成假设—验证假设—形成报告”的科学逻辑链封装为可复现、可审计、支持人在回路的七阶段标准流程。

软件适用的核心场景包括：文献调研与事实抽取、科学假设构建与评审、迭代实验设计与执行、科研报告撰写与影响力评估，以及开题报告、大创与挑战杯等赛事材料的准备。

软件的核心能力不在于单纯代写文本，而在于用机制约束大智能服务行为：以事实白名单杜绝编造引用，以判定式 Gate 拦截不可行方案，以大家长 智能体 统筹全局质量，并以审计链保留每一步决策依据。

本手册用于说明软件的用途、功能特点、运行要求和页面操作流程。各功能章节按用户能够看到的页面、入口、按钮、输入项、提示信息和处理结果进行说明。

## 三、功能特点

用户可在首页与项目列表页面用户登录后的起始页，用于浏览、搜索与进入已有科研项目，并作为创建新项目的入口。页面上的顶部品牌栏与导航（含“创建项目”入口）、项目卡片网格，每张卡片显示项目名称、研究领域、状态与最近一次 Pipeline 摘要、搜索框与状态筛选标签（草稿/进行中/已生成报告等）和首页 Footer 与最近 Pipeline 运行概览会集中呈现当前可操作内容，用户处理完成后可以看到筛选或搜索后列表实时更新，卡片显示最新状态和点击卡片后页面跳转到对应项目工作台，地址栏变为 /projects/{id}。

在新建科研项目页面中，用户主要处理录入一个科研任务的元信息，确定其运行模式（通用或联邦学习）、研究领域与初始约束，作为后续七阶段流程的输入。系统把项目名称、研究问题、研究领域、研究目标、已知背景输入框、项目模式选择（通用 general / 联邦学习 federated learning）、联邦学习模式下出现的 FL 档位与领域标签选择、关键词、数据来源、限制条件、期望输出等扩展字段和“创建”按钮与取消按钮放在当前操作区域，处理结束后会反馈创建成功后自动跳转到新建项目的工作台（/projects/{id}）和项目出现在首页列表，状态为“草稿”。

项目工作台与多 Tab 导航页面关注的是单个科研项目的统一操作台，把所有阶段相关页面聚合在多 Tab 布局中，用户在一个界面内完成全流程。用户通过顶部项目信息栏（名称、模式、状态）、左侧或顶部 Tab 栏：项目概览、研究问题、文献库、智能体工作流、候选假设、迭代实验、研究报告、Prompt 管理、运行日志和每个 Tab 对应的内容区与状态指示（加载中/空/错误三态）确认当前状态，并在操作结束后获得切换 Tab 后内容区刷新为对应阶段数据与控件和阶段状态变化会反映在项目信息栏与 Tab 角标上。

用户可在智能体工作流运行（七阶段 Pipeline）页面可视化并驱动七阶段科研流水线，展示每个阶段的进度、输出与运行过程事件，是系统核心操作页面。页面上的阶段进度条（PipelineProgress），七个阶段按序高亮、当前阶段产出文本/结构化结果展示区、运行过程时间线（ClosedLoopTimeline）显示 CQS 趋势、运行过程事件与决策、“启动 Pipeline / 继续 / 导出审计链”按钮和HITL Gate 弹窗（出现时）会集中呈现当前可操作内容，用户处理完成后可以看到阶段切换时进度条与高亮更新，产出区刷新和完成后显示综合质量分与“已修复/修复中”状态；审计链可导出。

在文献库与事实白名单（证据链抽屉）页面中，用户主要处理管理项目文献，并呈现由文献挖掘提取的事实白名单与可溯源的证据链，让用户核对假设引用的真实来源。系统把文献列表（标题、来源、导入状态）、上传/导入（arXiv）按钮与进度、事实白名单条目，每条带 fact_id、证据级别徽标（EvidenceLevelBadge）和证据链抽屉（EvidenceChainDrawer）显示 fact 与 source_chunk_id 的对应关系放在当前操作区域，处理结束后会反馈上传/导入后文献进入列表，状态从“处理中”变为“已完成”和事实白名单条目带上 fact_id 与级别徽标，点击可回放来源。

候选假设与评审（人在回路 Gate）页面关注的是展示假设生成与评审结果，提供五维评分、证据级别与人工审核 Gate，让用户决定假设是否进入实验。用户通过假设卡片列表（HypothesisCard），含假设陈述、证据级别、五维评分、每条假设的 fact 引用与可检验性说明、人工审核 Gate 弹窗（HitlGateModal）与继续条（HitlGateContinueBar）和“通过/退回修改”按钮与评审摘要确认当前状态，并在操作结束后获得通过后假设状态变更，继续条提示可进入下一阶段和退回后假设回到修订队列，用户可在工作流中看到重试。

用户可在迭代实验与运行决策页面绑定真实数据、设计分析脚本并按反馈多轮执行实验，结合反事实预演与多轮实验决策，把假设推向可验证结论。页面上的数据绑定与实验循环配置面板（LoopConfigPanel）、反事实预演面板（CounterfactualPreviewPanel）显示失败模式与转向建议、迭代轮次面板（IterationRoundPanel）展示每轮结果、指标与状态和“运行 / 采纳结果 / 触发证据链迭代”按钮会集中呈现当前可操作内容，用户处理完成后可以看到每轮运行后指标与状态刷新，运行过程时间线记录决策和采纳结果后该实验出现在报告可引用列表中。

在研究报告生成与导出页面中，用户主要处理查看系统生成的研究报告，导出多种格式与完整审计链，供复盘、提交或赛事材料使用。系统把报告列表（标题、生成时间、状态）、报告预览区（Markdown 渲染，含章节、参考文献、图表）、“导出 PDF / Markdown / 审计链”按钮和质量分与修复状态标记放在当前操作区域，处理结束后会反馈导出后浏览器下载对应文件，报告页显示“已导出”提示和LaTeX 源码 report.tex 始终生成，可手动编译。

## 五、首页与项目列表

用户可在首页与项目列表页面用户登录后的起始页，用于浏览、搜索与进入已有科研项目，并作为创建新项目的入口。用户可以通过浏览器访问 http://localhost:5173 后默认进入首页（页面入口 /）。

科研人员每天打开系统第一眼看到的就是首页：这里列出自己参与的全部项目，可按名称或状态筛选，也能从首页直接进入某个项目的工作台或发起新项目。

用户在首页与项目列表页面会看到顶部品牌栏与导航（含“创建项目”入口）、项目卡片网格，每张卡片显示项目名称、研究领域、状态与最近一次 Pipeline 摘要、搜索框与状态筛选标签（草稿/进行中/已生成报告等）和首页 Footer 与最近 Pipeline 运行概览等信息，并可依据页面显示继续处理。

使用该功能时，用户先在搜索框输入项目关键字，或点击状态标签筛选列表，随后点击某张项目卡片，进入该项目的多 Tab 工作台，最后点击右上角“创建项目”按钮，跳转到新建项目页。

页面会按照无项目时列表显示空状态提示，引导用户点击创建项目和搜索为空时返回“无匹配项目”提示，不报错等规则限制或提示用户。处理结束后，用户可以看到筛选或搜索后列表实时更新，卡片显示最新状态和点击卡片后页面跳转到对应项目工作台，地址栏变为 /projects/{id}。

## 六、新建科研项目

用户可在新建科研项目页面录入一个科研任务的元信息，确定其运行模式（通用或联邦学习）、研究领域与初始约束，作为后续七阶段流程的输入。用户可以通过首页点击“创建项目”，或访问 /projects/new。

当用户有一个新的研究想法（例如“部分类不相交数据下的联邦学习鲁棒性”）要系统化推进时，在此页填写研究问题、目标与约束，建立项目骨架。

该部分提供项目名称、研究问题、研究领域、研究目标、已知背景输入框、项目模式选择（通用 general / 联邦学习 federated learning）、联邦学习模式下出现的 FL 档位与领域标签选择、关键词、数据来源、限制条件、期望输出等扩展字段和“创建”按钮与取消按钮等页面内容，用户可据此查看状态、填写信息或选择下一步操作。

在该页面中，用户先填写项目名称与研究问题（必填），随后选择项目模式；若选联邦学习，继续选择 FL 档位与领域标签，接着填写研究目标、背景、约束与期望输出等可选项，最后点击“创建”，系统生成项目并返回工作台。

如果不满足项目名称与研究问题为必填，留空时按钮置灰或提示“请填写必填项”、联邦学习模式必须至少选择一个 FL 档位，否则提示选择后再创建和研究问题长度建议具体可检验，过长会给出精简提示但不强制等要求，用户需要根据页面提示调整后再继续。页面反馈通常包括创建成功后自动跳转到新建项目的工作台（/projects/{id}）和项目出现在首页列表，状态为“草稿”。

## 七、项目工作台与多 Tab 导航

用户可在项目工作台与多 Tab 导航页面单个科研项目的统一操作台，把所有阶段相关页面聚合在多 Tab 布局中，用户在一个界面内完成全流程。用户可以通过首页点击项目卡片，或访问 /projects/:id。

用户进入具体项目后，日常所有操作都在工作台进行：切到不同 Tab 分别处理问题、文献、假设、实验与报告，无需在多个系统间跳转。

页面上主要呈现顶部项目信息栏（名称、模式、状态）、左侧或顶部 Tab 栏：项目概览、研究问题、文献库、智能体工作流、候选假设、迭代实验、研究报告、Prompt 管理、运行日志和每个 Tab 对应的内容区与状态指示（加载中/空/错误三态）等内容，这些内容用于帮助用户确认当前位置和可执行操作。

实际操作时，用户先在 Tab 栏点击目标阶段对应的标签，随后在当前 Tab 内完成该阶段操作（如研究问题 Tab 查看/编辑问题陈述），最后需要深入配置时，通过高级深链进入 Prompt 管理或运行日志 Tab。

操作过程中需要注意联邦学习模式才显示联邦相关面板，通用模式自动隐藏对应入口和Tab 内容区加载失败显示错误态与重试提示，不空白卡死。操作完成后，系统会显示切换 Tab 后内容区刷新为对应阶段数据与控件和阶段状态变化会反映在项目信息栏与 Tab 角标上。

## 八、智能体工作流运行（七阶段 Pipeline）

用户可在智能体工作流运行（七阶段 Pipeline）页面可视化并驱动七阶段科研流水线，展示每个阶段的进度、输出与运行过程事件，是系统核心操作页面。用户可以通过项目工作台 → “智能体工作流”Tab（WorkflowPage）。

用户在工作流 Tab 启动一次完整科研运行，实时观察问题理解→文献挖掘→知识缺口→假设生成→假设评审→迭代实验→报告生成的推进，并在人为审核节点介入。

用户在智能体工作流运行（七阶段 Pipeline）页面会看到阶段进度条（PipelineProgress），七个阶段按序高亮、当前阶段产出文本/结构化结果展示区、运行过程时间线（ClosedLoopTimeline）显示 CQS 趋势、运行过程事件与决策、“启动 Pipeline / 继续 / 导出审计链”按钮和HITL Gate 弹窗（出现时）等信息，并可依据页面显示继续处理。

使用该功能时，用户先点击“启动 Pipeline”，系统按七阶段顺序执行，随后观察进度条与每个阶段产出；遇到人工审核 Gate 时，在弹窗中查看证据并选择通过或退回，接着某阶段完成后可点击查看详细输出；运行结束在运行过程时间线查看质量趋势，最后点击“导出审计链”下载本次运行的 JSONL 决策记录。

页面会按照启动前需至少填写研究问题，否则提示先到研究问题 Tab 补全、HITL Gate 未处理时流程暂停，需专家通过或退回方可继续和无 Qwen Key 且未开模拟模式时，启动会提示配置凭证等规则限制或提示用户。处理结束后，用户可以看到阶段切换时进度条与高亮更新，产出区刷新和完成后显示综合质量分与“已修复/修复中”状态；审计链可导出。

## 九、文献库与事实白名单（证据链抽屉）

用户可在文献库与事实白名单（证据链抽屉）页面管理项目文献，并呈现由文献挖掘提取的事实白名单与可溯源的证据链，让用户核对假设引用的真实来源。用户可以通过项目工作台 → “文献库”Tab（LiteratureLibrary）；证据链抽屉由假设或事实链接打开。

用户在文献库 Tab 上传论文或导入检索结果后，想确认系统到底依据哪些文献事实生成了假设，可打开证据链抽屉查看每条 fact 的来源与证据级别。

该部分提供文献列表（标题、来源、导入状态）、上传/导入（arXiv）按钮与进度、事实白名单条目，每条带 fact_id、证据级别徽标（EvidenceLevelBadge）和证据链抽屉（EvidenceChainDrawer）显示 fact 与 source_chunk_id 的对应关系等页面内容，用户可据此查看状态、填写信息或选择下一步操作。

在该页面中，用户先点击“上传”选择本地 PDF/DOCX，或点击“导入”检索并添加 arXiv 文献，随后等待文献挖掘完成，列表中显示已提取的事实数量，接着点击某条事实或假设中的 fact 引用，打开证据链抽屉查看来源原文与来源块标识，最后根据证据级别（high/medium/low）判断该事实的可信度。

如果不满足仅支持 PDF/DOCX/TXT/MD/CSV 等文本类文献，其他格式提示不支持、文献解析失败显示错误态与重试入口，不阻断其他文献和证据级别为 low 的事实在假设生成时会被要求补强或标注等要求，用户需要根据页面提示调整后再继续。页面反馈通常包括上传/导入后文献进入列表，状态从“处理中”变为“已完成”和事实白名单条目带上 fact_id 与级别徽标，点击可回放来源。

## 十、候选假设与评审（人在回路 Gate）

候选假设与评审（人在回路 Gate）页面展示假设生成与评审结果，提供五维评分、证据级别与人工审核 Gate，让用户决定假设是否进入实验。用户可以通过项目工作台 → “候选假设”Tab（HypothesesPage）；HITL 弹窗在评审 Gate 触发时自动出现。

用户在假设评审阶段后，于候选假设 Tab 查看系统产出的多条假设及其评分，对关键假设做人工通过/退回，控制自动化流程的走向。

页面上主要呈现假设卡片列表（HypothesisCard），含假设陈述、证据级别、五维评分、每条假设的 fact 引用与可检验性说明、人工审核 Gate 弹窗（HitlGateModal）与继续条（HitlGateContinueBar）和“通过/退回修改”按钮与评审摘要等内容，这些内容用于帮助用户确认当前位置和可执行操作。

实际操作时，用户先浏览假设卡片，查看五维评分与证据级别徽标，随后点击某条假设展开其 fact 引用与评审摘要，接着出现审核 Gate 时，在弹窗中阅读系统提示，选择“通过”或“退回修改”，最后退回的假设会回到生成/修订环节，通过后进入迭代实验。

操作过程中需要注意审核 Gate 必须通过或退回其中之一，不能跳过、证据级别为 low 的假设在通过前会被提示需补强证据和退回需填写简要理由，否则按钮置灰。操作完成后，系统会显示通过后假设状态变更，继续条提示可进入下一阶段和退回后假设回到修订队列，用户可在工作流中看到重试。

## 十一、迭代实验与运行决策

用户可在迭代实验与运行决策页面绑定真实数据、设计分析脚本并按反馈多轮执行实验，结合反事实预演与多轮实验决策，把假设推向可验证结论。用户可以通过项目工作台 → “迭代实验”Tab。

用户在假设评审通过后，于迭代实验 Tab 选择数据、配置实验循环、查看反事实预演（失败模式预警），并基于每轮结果决定是否继续或转向。

用户在迭代实验与运行决策页面会看到数据绑定与实验循环配置面板（LoopConfigPanel）、反事实预演面板（CounterfactualPreviewPanel）显示失败模式与转向建议、迭代轮次面板（IterationRoundPanel）展示每轮结果、指标与状态和“运行 / 采纳结果 / 触发证据链迭代”按钮等信息，并可依据页面显示继续处理。

使用该功能时，用户先在循环配置面板选择数据集并设定实验参数，随后查看反事实预演给出的失败风险与最小成本验证建议，接着点击“运行”，系统先小样本预检再执行 full 迭代，之后逐轮查看指标；证据不足时点击“触发证据链迭代”回到文献补搜，最后确认结论后采纳结果，供报告引用。

页面会按照未绑定数据不得进入脚本设计或运行，提示先选数据、小样本预检不通过会阻断 full 运行，要求修正方案和高风险且无廉价验证手段的路径会被标记，需人工确认继续等规则限制或提示用户。处理结束后，用户可以看到每轮运行后指标与状态刷新，运行过程时间线记录决策和采纳结果后该实验出现在报告可引用列表中。

## 十七、典型使用流程

用户完成一次完整业务时，通常先进入联邦智研 AI 科研自动化系统，再选择或创建业务对象，随后按照页面提示处理内容并查看结果。

## 十八、常见问题解答

问题：没有 Qwen API Key 能跑通流程吗？
解决方法：可以。在 backend/.env 中设置 USE_MOCK_LLM=true，系统用模拟输出跑通完整七阶段流程；但模拟结果不可用于正式科研提交，仅用于体验与调试。

问题：Pipeline 启动后卡住或失败怎么办？
解决方法：多数失败源于 LLM API 超时或欠费，而非软件本体的逻辑问题。可在设置页确认 Key 有效后重试；界面会在修复状态区显示“修复中/已修复”，失败重试通常在工作流页可见。

问题：联邦学习功能在哪里开启？
解决方法：在“新建项目”页把项目模式选为 federated learning，并选择 FL 档位与领域标签；通用模式下联邦相关面板自动隐藏，调用会返回 FL MODE REQUIRED。

问题：报告如何导出供提交或参赛？
解决方法：在“研究报告”或报告中心打开报告，点击“导出 PDF/Markdown”下载正文，点击“导出审计链”下载 JSONL 决策记录，二者配合即可作为可追溯的科研交付物。

问题：人在回路审核 Gate 是什么，必须处理吗？
解决方法：它是关键节点的专家审核弹窗，用于通过或退回假设与报告。未处理时流程会暂停，必须由专家选择通过或退回后才能继续，目的是在失控前纠偏。

| 术语 | 解释 |
| --- | --- |
| Pipeline（科研流水线） | 系统把科研过程拆成的七阶段标准流程：问题理解、文献挖掘、知识缺口、假设生成、假设评审、迭代实验、报告生成，按顺序由智能体执行。 |

| 审计链 | Pipeline 运行过程中记录的事件、决策与质量趋势清单（JSONL），可导出回放，证明每一步结论的依据。 |
| 联邦学习 Starter Pack | 系统以内容注入方式提供的联邦学习文献种子、数据集元数据与本地可跑脚本，作为通用科研能力的扩展演示场景，非核心技术主体。 |
| 科学影响力预测（评分表系统） | 延伸模块，对生成报告做四维（文本质量/声誉网络/未来影响/偏差公平）早期影响力评估，并量化不确定性、识别光环效应等偏差。 |
