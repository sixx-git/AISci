# 前端手动测试清单

## 环境准备
- [ ] 确保后端服务已启动（运行在 http://localhost:8000）
- [ ] 确保前端服务已启动（运行在 http://localhost:5173）
- [ ] 确保已配置好 API 密钥
- [ ] 确保数据库已初始化

## 页面导航测试
### 首页 (Home)
- [ ] 访问 http://localhost:5173 应显示首页
- [ ] 首页应包含创建项目按钮
- [ ] 首页应展示项目列表（如果有项目）
- [ ] 点击"创建新项目"应跳转到创建项目页面

### 创建项目页面 (CreateProject)

### 研究页面 (Research)

- [ ] "启动研究"按钮可用

### 结果页面

### 设置页面 (Settings)

## 交互流程测试
### 完整研究流程
1. 创建项目
   - [ ] 填写完整项目信息
   - [ ] 成功创建项目
   - [ ] 跳转到工作区

2. 上传文档
   - [ ] 选择并上传 2-3 篇文档
   - [ ] 文档处理完成后显示在列表中
   - [ ] 文档解析状态为"已完成"

3. 启动 Pipeline
   - [ ] 点击"启动研究"按钮
   - [ ] Pipeline 开始执行
   - [ ] 各阶段按顺序执行
   - [ ] 每个阶段状态正确更新
   - [ ] Pipeline 完成后跳转到结果页面

4. 查看结果
   - [ ] 结果页面正确显示
   - [ ] 所有生成内容正确展示
   - [ ] 可以下载研究报告
