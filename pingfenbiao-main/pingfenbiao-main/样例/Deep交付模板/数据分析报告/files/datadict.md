# Data Dictionary: FL Training Metrics

## 文件说明
本数据集记录了联邦学习实验过程中，不同算法(FedAvg/FedProx)在不同数据异构程度(Alpha参数)下的训练指标。

## 核心变量定义

| 字段名称 | 数据类型 | 定义与物理意义 | 单位/范围 | 备注 |
|----------|----------|----------------|-----------|------|
| Round | 整数 | 全局通信轮次 | [1, 100] | 每轮包含：下发模型→本地训练→上传更新→全局聚合 |
| Alpha | 浮点数 | Dirichlet分布集中度参数，量化Non-IID程度 | {0.1, 0.5, 1.0, 5.0, 10.0} | α→0表示极端异构；α→∞表示IID。本实验使用5个代表性等级 |
| Algorithm | 字符串 | 聚合算法类型 | {FedAvg, FedProx} | FedProx含近端项(μ=0.01)，理论上对Non-IID更鲁棒 |
| Global_Loss | 浮点数 | 全局模型在验证集上的交叉熵损失 | [0, +∞) | 在服务器端10k张平衡测试图像上计算；值越小越好 |
| Global_Accuracy | 浮点数 | Top-1分类准确率 | [0, 100]% | 模型泛化能力的最终评价指标 |
| Weight_Divergence | 浮点数 | 局部模型与全局模型的权重差异范数 | [0, +∞) | 计算公式: ‖W_local - W_global‖₂；Client Drift的核心量化指标 |
| Client_Variance | 浮点数 | 各客户端模型更新之间的方差 | [0, +∞) | 反映客户端间梯度方向的离散程度 |

## 关键派生指标计算方式

### 1. 收敛判定标准
- **稳态定义**: 连续10轮Global_Accuracy波动幅度 < 0.2%
- **收敛轮数**: 首次达到稳态的Round数
- **注意**: 若100轮内未达稳态，记为"未收敛"

### 2. Non-IID程度量化
- **理论依据**: Alpha值直接对应标签分布的偏斜程度
- **经验对应**:
  - Alpha=0.1: 极端Non-IID（多数客户端仅1-2类样本）
  - Alpha=0.5: 显著Non-IID
  - Alpha=1.0: 中度Non-IID
  - Alpha=5.0: 轻度Non-IID
  - Alpha=10.0: 近似IID

### 3. Client Drift强度
- **直接指标**: Weight_Divergence的稳态值
- **关联指标**: Client_Variance与收敛速度负相关

## 数据质量说明

### 缺失值编码
- **标记方式**: -1.0 或 NaN
- **出现场景**: 约5%的早期轮次(Round≤5)因网络延迟导致记录失败
- **处理建议**: 线性插值或剔除（需明确说明）

### 异常值识别
- **物理约束**: 
  - Global_Accuracy应单调递增（允许±2%噪声波动）
  - Weight_Divergence应随Round递增（客户端漂移累积）
  - 若出现连续3轮下降，可能为异常

### 数据一致性
- 所有Accuracy已归一化为百分比(0-100)
- Loss与Accuracy呈明确负相关（皮尔逊相关系数应<-0.9）
- 同Alpha条件下，FedProx的最终Accuracy应≥FedAvg（Non-IID场景）

## 实验设计约束（分析时必须考虑）

| 约束项 | 具体设置 | 对分析的影响 |
|--------|----------|--------------|
| 客户端总数 | 100 | 每轮采样率C=0.1，即10个客户端参与 |
| 本地训练轮数 | E=5 | 本地模型与全局模型差异的来源 |
| 批次大小 | 32 | 影响梯度噪声水平 |
| 学习率 | 0.01 (恒定) | 排除学习率调度对收敛的影响 |
| 模型架构 | 5层CNN | CIFAR-10优化结构 |

## 可验证的分析结论（数据支持的）

1. **收敛速度对比**: Alpha=10.0 vs Alpha=0.1的收敛轮数差异
2. **算法优劣**: FedProx vs FedAvg在不同Alpha下的最终Accuracy差距
3. **漂移量化**: Weight_Divergence与Alpha的定量关系
4. **敏感性分析**: 改变收敛阈值(如0.2%→0.5%)对结论的影响
