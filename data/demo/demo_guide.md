# AI Scientist Demo 运行指南

本指南将帮助您使用 demo 数据测试 AI Scientist MVP 系统的完整功能。

## 前置条件

1. 确保已按照项目文档配置好后端和前端
2. 确保数据库已初始化
3. 确保 Qwen API 密钥已配置

## Demo 使用步骤

### 步骤 1：创建新项目

1. 启动系统并访问前端界面
2. 点击 "创建新项目" 按钮
3. 填写项目信息：
   - **项目名称：** 城市热岛效应影响因素分析
   - **研究领域：** 城市气候/环境科学
   - **研究问题：** （可以复制 `research_question.md` 中的内容）
   - **描述：** 基于公开气象数据的城市热岛效应影响因素分析

### 步骤 2：上传文献

1. 进入项目工作区的 "文档" 页面
2. 点击 "上传文档" 按钮
3. 上传 `data/demo/documents/` 目录下的三个文献文件：
   - `literature_1.md`
   - `literature_2.md`  
   - `literature_3.md`
4. 等待文献解析和向量化完成

### 步骤 3：启动研究 pipeline

1. 进入 "研究" 页面
2. 点击 "启动研究 pipeline"
3. 按照以下顺序执行研究步骤：

   - **阶段 1：问题理解** - 系统会自动分析研究问题
   - **阶段 2：文献挖掘** - 从已上传文献中提取科学事实
   - **阶段 3：知识缺口分析** - 分析研究空白和机会
   - **阶段 4：假设生成** - 生成多个科学假设
   - **阶段 5：假设评审** - 评估并选择最佳假设
   - **阶段 6：实验设计** - 为选定的假设设计实验方案
   - **阶段 7：小样验证** - 使用 CSV 数据进行小样本验证
   - **阶段 8：报告生成** - 生成最终的研究报告

### 步骤 4：查看和导出结果

1. pipeline 执行完成后，在 "结果" 页面查看所有成果
2. 可以查看、下载研究报告（Markdown 和 PDF 格式）
3. 查看生成的科学假设、实验设计和验证结果

### 步骤 5：使用 CSV 数据进行验证（可选）

在小样验证阶段，可以：
1. 选择上传的 `urban_climate_data.csv` 文件
2. 系统会自动分析数据并验证假设
3. 生成可视化图表和统计结果

## 数据文件说明

| 文件 | 说明 |
|------|------|
| `research_question.md` | 详细的研究问题说明 |
| `urban_climate_data.csv` | 模拟的城市气候数据，包含 8 个观测点，2024 年夏季数据 |
| `literature_1.md` | 关于城市热岛与土地利用关系的示例文献 |
| `literature_2.md` | 关于植被降温效应的示例文献 |
| `literature_3.md` | 关于建筑形态与微气候关系的示例文献 |

## 预期成果

运行完完整的 demo pipeline 后，您将获得：
1. 问题理解和文献综述
2. 3-5 个科学假设及评分
3. 完整的实验设计方案
4. 基于 CSV 数据的小样验证结果
5. 一份完整的研究报告（含论文题目、摘要、方法、参考文献等）

## 故障排除

### 问题：文献上传失败
- 确保文件格式为文本格式
- 检查文件大小不超过限制

### 问题：LLM 调用超时
- 检查 API 密钥配置
- 可以尝试分步执行 pipeline

### 问题：PDF 生成失败
- 检查是否安装了必要的依赖包
- 可以使用 Markdown 格式的报告作为替代

## 演示建议

对于课程演示，建议按以下流程进行：
1. 展示项目创建和文献上传
2. 重点演示假设生成和评审阶段
3. 展示实验设计和小样验证的结果
4. 最后展示生成的完整研究报告
