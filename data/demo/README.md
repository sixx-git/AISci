# AI Scientist Demo 数据

这是为 AI Scientist MVP 项目准备的完整 demo 数据集，用于展示系统的功能。

## 研究主题

**基于公开气象数据的城市热岛效应影响因素分析**

### 研究背景

城市热岛效应（Urban Heat Island, UHI）是指城市中心区域的温度明显高于周围郊区的现象，是城市化进程中的典型生态环境问题。随着全球变暖和城市扩张的加速，热岛效应日益显著，对城市生态环境、居民生活质量和能源消耗都产生了重要影响。

### 研究问题

**主要研究问题：**
1. 哪些城市要素对热岛效应的影响最为显著？
2. 城市绿化率与热岛强度之间存在怎样的量化关系？
3. 建筑密度和不透水面覆盖率对城市温度的影响机制是什么？

**具体研究任务：**
- 收集和整理城市气候监测数据、土地利用数据等
- 分析热岛效应与各影响因素之间的相关性
- 构建热岛效应影响因素的预测模型
- 提出缓解城市热岛效应的建议和策略

### 数据说明

本 demo 包含以下数据：

1. **气象与环境数据（CSV）**：模拟的城市气象监测数据
2. **示例文献（PDF 元数据）**：3 篇相关研究论文的模拟数据
3. **演示说明文档**：本文件
